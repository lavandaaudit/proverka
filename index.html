СТАН ЕКСПЕРИМЕНТУ
Поле культур під впливом сонячних даних NOAA.

Як сонячні явища та погодні дані впливають на поле:
• Вища SSN → швидший ріст культур, яскравіше поле
• Зростання сонячної активності → швидше дозрівання, більше "витків" трактора
• Геомагнітні бурі / високий Kp → локальні пульсації рослин
• Спокійне сонце → рівне поле, спокійний ріст
• Різкі спалахи (X/M-класу) → короткочасні тремтіння рослин
• Протонні події (SEP) → випадкові "деформації" окремих культур
• Корональні викиди маси (CME) → глобальні пульсації всього поля
